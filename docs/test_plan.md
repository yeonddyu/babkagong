## 3. 대표 시나리오 (4.7)
1. 제약을 한 번에 충족 — "강남역에서 점심 먹고 카공할 건데 추천해줘"
2. 재계획 필요 — 낮은 예산 + 음식 종류
3. 상한 도달 — 충족 불가능한 예산
4. Tool 하나 실패 — 카카오/기상청 실패 상태
5. Tool 불필요 — "안녕", "사용법 알려줘"
6. 날씨 — 비/추위 반영, 7. 후속 요청 맥락, 8. 계획 저장 충돌
